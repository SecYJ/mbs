# Client Instructions

## Coding Conventions

Before writing, modifying, or reviewing client code, read and follow the documents relevant to the task. Paths below are relative to `client/`; load each document only when its topic applies.

| When working on | Read |
| --- | --- |
| React components, hooks, or UI state | [React conventions](docs/react-conventions.md) |
| Tailwind classes or `className` values | [Styling conventions](docs/styling-conventions.md) |
| Designing or changing the visual appearance of a screen | [Design guidelines](../docs/design-guidelines.md) |
| Writing, changing, or reviewing client tests | [Testing guide](test/README.md) |
