# Coding Style

Applies to JavaScript and TypeScript code, including React components.

## Functions

- Use function declarations for standalone functions.
- Use arrow functions for callbacks passed to another function.
- For object methods, use method shorthand instead of arrow-function properties. Single-expression arrow functions (without a block body) are allowed as an exception, even if the formatter wraps the expression across multiple lines.

## TypeScript

- Use type aliases instead of interfaces.
- Prefer inferred return types over explicit return type annotations.
